phryzby — physics written in Ruby

A law should read the way it is written on a blackboard and still be executable. Inside an equation block the variables are not numbers — they are nodes in an expression tree, so == builds an equation instead of answering true or false. The solver finds a root of left − right afterwards, which is why one declaration answers in any direction: give it two angles and it names the material.

Every page runs CRuby compiled to WebAssembly and evaluates this repository's own .rb files — the same bytes the tests run. Edit a law in the page and run it again.

The machinery

  • 0 The engine What a law is made of: an expression tree where == builds instead of compares, the scope a declaration runs in, and a solver that does not care which side of the equals sign the unknown was on.

Light

  • 1.1 Reflection One equation, and what it means for == to build rather than compare. A law is a module; Interface is the surface it holds for.
  • 1.2 Refraction A second law included alongside the first, neither a kind of the other. Declared domains, because a periodic law has infinitely many roots and only one is physical. Total internal reflection as a condition rather than a special case.
  • 1.3 Reflectance Fresnel: how much goes each way. Three equations, an interface that now holds all three laws, and the solver choosing between them. Brewster's angle and the meaning of the word total fall out rather than being stated.
