phryzby — play with the laws of physics

You write a law down once, the way it appears on a blackboard, and never rearrange it. Which means you can change it. Say a mirror should turn light by half the angle it arrives at rather than all of it — edit that line in the browser, and every answer on the page follows the law you just invented. There is no derivation to redo, because there was never a formula: only an expression tree and a root to find.

Inside an equation block the names are not numbers — they are nodes in that tree, so == builds an equation instead of answering true or false. Asking is a separate act: name the unknown, and a solver finds a root of left − right. The solver never learns what the law says, which is why one declaration answers in every direction — and why an invented law costs exactly what a true one does.

the whole of lib/light/refraction.rb

require_relative "../physics"

module Refraction
  extend Physics::Law

  quantity :angle_of_incidence,  variable: :i,  within: Physics::A_RIGHT_ANGLE
  quantity :angle_of_refraction, variable: :rr, within: Physics::A_RIGHT_ANGLE
  quantity :refractive_index_of_first_medium,  variable: :mu1
  quantity :refractive_index_of_second_medium, variable: :mu2

  equation(:snells_law) { mu2 / mu1 == sin(i) / sin(rr) }

  condition(:total_internal_reflection) { sin(i) * mu1 / mu2 > 1 }
end

and every question it answers

glass = Physics::Scenario[Refraction]

glass.new(i: 30.deg, mu1: 1.0, mu2: 1.5)
     .solve(:rr).in_degrees
=> 19.4712     # the refracted ray

glass.new(i: 30.deg, rr: 19.4712.deg, mu1: 1.0)
     .solve(:mu2)
=> 1.5000      # the material itself

glass.new(rr: 90.deg, mu1: 1.5, mu2: 1.0)
     .solve(:i).in_degrees
=> 41.8103     # the critical angle

Nothing above was rearranged, and no second formula exists for the critical angle — it is Snell asked with the refracted ray lying flat. Laws are modules, so a scenario names the ones that hold where the question is being asked. Ask a Fresnel page for the reflectance alone and the solver works backwards to what it needs first.

Every chapter below runs CRuby compiled to WebAssembly and evaluates this repository's own .rb files — the same bytes the tests run. Edit a law in the page, and the diagram beside it changes.

The machinery

  • 0 The engine What a law is made of: an expression tree where == builds instead of compares, the scope a declaration runs in, and a solver that does not care which side of the equals sign the unknown was on.

Light

  • 1.1 Incidence One quantity and no law at all — a full name, the short name the equations will use, and the branch it lives on. Declaring is not solving: ask a scenario that was given nothing and it refuses. Every later law begins include Incidence.
  • 1.2 Reflection The first equation, and what it means for == to build rather than compare. A law is a module and holds nothing; Physics::Scenario[Reflection] is what holds values and solves.
  • 1.3 Refraction A second law composed alongside the first, neither a kind of the other. Declared domains, because a periodic law has infinitely many roots and only one is physical. The critical angle, which is not a formula anywhere — it is Snell asked with the refracted ray lying flat.
  • 1.4 Reflectance Fresnel: how much goes each way. Three more equations, and one question — solve(:r) — that reaches back through Snell for an angle nobody asked for. Then, past the critical angle, it runs out of answers.
  • 1.5 Total internal reflection A law that only sometimes holds. One equation, r == 1, guarded by when: — so the solver reaches for it only where Snell has no solution, and the word total stops being a claim in prose.

No gems, no build step, no framework. 85 tests, Ruby 3.4.
