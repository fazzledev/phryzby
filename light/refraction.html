Refraction — and the branch problem

      

        A ray meeting glass does both things at once, so the question names both laws:
        Physics::Scenario[Reflection, Refraction]. Neither law inherits the other —
        refraction is not a kind of reflection — and neither file mentions the other.
      

      

        A law includes only what it presupposes. Snell's law is about a ray that has
        already arrived, so this file begins include Incidence; it is not about a
        reflected one, so it says nothing of reflection. Two laws that merely both happen to hold
        are composed where the question is asked instead.

        The console under the code is a real irb against the same VM. Start with
        surface.solve(:rr), then ask the same law backwards — give it two angles and
        it names the material. surface is bound to whatever the sliders say, and
        anything you redefine in the editor is live there the moment you re-run.
      

      

        within: is doing real work here. sin is periodic, so Snell has
        infinitely many roots and only one of them is an angle light can take. Delete
        within: Physics::A_RIGHT_ANGLE from angle_of_refraction above,
        run it again, and drag down to a few degrees: Newton's method wanders off and returns a
        root several turns away.
      

      

        Past the critical angle Snell asks for a sine greater than one. There is no refracted ray
        at all — which is how an optical fibre keeps light inside itself. Set μ₁ above μ₂ and open
        the angle to watch it happen. The critical angle above is not a rearranged formula: it is
        this same law asked with the refracted ray lying flat along the surface, which is the last
        angle that still has one.
      

      

        Notice the two refractive indices declare no within: at all. They appear
        linearly in Snell's law, so it has exactly one root for them and a range would be
        decoration. A domain earns its place where an equation has more than one root — which here
        means the angles, and nothing else.
      

      

        Because a law is stored rather than compiled into a formula, one declaration answers in any
        direction: give it two angles and it names the material.
