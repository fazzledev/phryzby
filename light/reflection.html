notes

      

        Drag the dividers to resize the panes; double-click one to put it back. Tick
        auto-run and the laws re-evaluate when you stop typing, and the page boots Ruby
        by itself next time. Both settings are remembered between visits.
      

      

        Anything you change is marked the way an editor marks it: a bar in the gutter beside every
        line you touched — green for new, blue for altered — a red wedge where lines were taken
        out, a dot on the tab and an M in the tree. Revert edits puts
        this repository's own text back.
      

      

        The console under the code is a real irb against the same VM. Start with
        surface.solve(:rl) — that one call is the whole idea, because nothing in the
        file rearranges anything. surface is bound to whatever the sliders say, locals
        persist between lines, and anything you redefine in the editor is live there the moment you
        re-run.
      

      

        A law is a module, not a class, because a law is not a kind of another law. It states what
        it is about where it is written — full name, short name, and the branch each quantity lives
        on — so this file can be read on its own. Nothing holds values until you ask:
        Physics::Scenario[Reflection] composes the laws you name into something that
        does. Here that is one law; the next chapters add more to the same brackets.
      

      

        The solver is never told which way round the question goes. It finds the equation that
        mentions the unknown and nothing else unknown, then finds a root of
        left − right. Give it rl instead of i and the same
        declaration answers.
      

      

        Run downloads CRuby compiled to WebAssembly, about 30 MB, and evaluates the files in the
        tree unmodified — the same bytes the tests run.
